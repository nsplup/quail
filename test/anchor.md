## 3. 第三章节：脚注跳转测试
本章节测试脚注的跳转功能。以下段落中包含多个脚注引用，点击编号应能跳转到页面底部的脚注定义区。
Markdown 是一种轻量级标记语言[^1]，由 John Gruber 创建[^2]。它允许人们使用易读易写的纯文本格式编写文档[^3]。
本测试文档包含多个脚注：一个英文脚注[^note]、一个中文脚注[^中文脚注]、一个长文本脚注[^long]。
**请验证：**
1. 点击脚注引用编号 → 是否跳转到文末对应脚注定义？
2. 点击脚注定义处的返回符号（↩ 或 ⇧）→ 是否跳转回原引用位置？

## 脚注定义区
[^1]: Markdown 是一种轻量级标记语言，2004 年由 John Gruber 发布。
[^2]: John Gruber，美国博主、UI 设计师，Markdown 语言的共同创造者。
[^3]: 纯文本格式：指不包含字体、颜色等样式信息的文本文件。
[^note]: This is an English footnote for testing English footnote IDs.
[^中文脚注]: 这是一个中文 ID 的脚注，用于测试中文脚注标识符的兼容性。
[^long]: 这是一个长文本脚注，用于测试脚注包含多行内容时的显示与跳转效果。它还可以包含 `代码`、**粗体** 和 [链接](#页内锚点与脚注跳转测试文档)。
[^mixed]: 混合场景脚注：当你跳转到这里时，请尝试返回第四章节。
[^first]: 第一个连续脚注。
[^second]: 第二个连续脚注。
[^reuse]: 这个脚注被引用了多次，测试多次引用回跳。
