## 17. HTML 表格：合并单元格与嵌套

测试点：Markdown 原生表格不支持合并单元格，使用 HTML 表格测试 `rowspan`、`colspan`。

<table>
  <thead>
    <tr>
      <th>列A</th>
      <th>列B</th>
      <th>列C</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td rowspan="2">跨行</td>
      <td colspan="2">跨列</td>
    </tr>
    <tr>
      <td>B2</td>
      <td>C2</td>
    </tr>
  </tbody>
</table>

Markdown 表格单元格内嵌套 HTML 表格：

| 场景 | 内容 |

| HTML 嵌套表格 | <table><tr><td>内1</td><td>内2</td></tr><tr><td>内3</td><td>内4</td></tr></table> |
